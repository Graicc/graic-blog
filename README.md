# Graic Blog

Personal blog. Available at <https://graic.net>

This blog is built in [Svelte](https://svelte.dev) using [MDsveX](https://github.com/pngwn/MDsveX) to process Markdown posts (`/src/posts/`). A static site is generated and deployed by [CloudFlare Pages](https://pages.cloudflare.com) on commits to main.
