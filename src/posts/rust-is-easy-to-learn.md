<QuoteBox quote="There are only two kinds of languages: the ones people complain about and the ones nobody uses." author="Bjarne Stroustrup" />

Everything is an expression:

- No ternary. [just] use if.
- Only one switch (compared to python or C# with two switch)

You don't need these features:

- Constructors
- Inheritance
- Multiple Inheritance
- Exceptions
- Null

The language doesn't suck:

- Build system
- Package manager
- No header bs
- Operator overloads are just traits
- No falsey / truthy values
